# BlackMamba Insights Roadmap

## P0 — Catalog Curation

The immediate goal is to make the existing catalog clean before adding more visual depth.

### Audit
For every SoundCloud track, detect:
- missing artwork
- missing artist metadata
- missing genre
- missing tags
- missing description

### Queue
Prioritize:
1. missing artwork
2. missing artist metadata
3. missing genre / tags
4. missing description
5. within the same tier, higher-play tracks first

### Curate
From the private BlackMamba session:
- upload or replace cover art
- edit title
- edit artist metadata
- edit genre
- edit tags
- edit description
- save changes to the real SoundCloud track

### Completion
A track is **curated** when all five core curation fields are present.

## P1 — Curation Quality

- reusable metadata presets
- bulk apply artist / genre / tags
- album-aware consistency
- identify duplicate or suspicious artwork
- progress history and curation percentage

## P2 — Analytics

- hourly/daily snapshots
- 1h / 3h / 24h / 7d velocity
- country/city map
- catalog performance buckets

## P3 — Waveform Experience

The mini sinusoidal control stays for now.

Later:
- render the real waveform signature from SoundCloud's waveform data
- track-detail waveform view
- waveform-linked comments and history

## P4 — Multi-platform

- Spotify
- YouTube
- other distribution sources
